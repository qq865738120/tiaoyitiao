# 跳一跳：Cocos 核心玩法学习项目

这是两个对比工程共同的素材与实施基线，Creator 版本为 **3.8.8**。目前交付的是素材、参考资料、文档和阶段命令；游戏代码、场景及阶段验收尚未实施。

从 [文档导航](docs/README.md) 开始阅读。Game Agent 0.4.0 已分别安装在两个工程的 `extensions/game-agent`，阶段命令位于各自的 `.gameagent/commands`。

## 使用顺序

1. 通过 Cocos Dashboard 打开当前工程。
2. 打开 Game Agent 面板，在命令菜单的项目命令中选择“跳一跳 · 01 基础结构与3D场景”，之后按 02—04 顺序执行。
3. 每阶段完成真实预览、必要测试及交接记录后再进入下一阶段。命令只针对当前工程，不自动同步或修改另一工程。

## 共同目录

| 目录 | 内容 |
| --- | --- |
| `assets/resources/jump/original` | 原包全部 185 个媒体文件，另有应用图标 |
| `assets/resources/jump/derived` | 46 个静态 GLB、7 张背景、8 张图集裁片、2 张兼容纹理及字体参考 JSON |
| `docs/参考截图` | 用户补充的开始、结算、游戏中三张截图 |
| `docs/参考资料/原始提取包` | 完整提取成果、原代码及离线素材浏览器，位于资产编译目录之外 |
| `docs/实施阶段` | 4 个阶段的任务、前置条件和验收要求 |
| `.gameagent/commands` | 4 个项目自定义命令，与文档提示词同源 |
| `docs/数据` | 逐文件来源、用途、UUID、子资源及一致性证据 |

排行榜、消息、皮肤中心、多人游戏不实施；分享、活动奖励、广告、授权登录和微信宿主界面也不属于本次核心玩法。相关资源保留为档案，不代表要实现这些功能。

素材命名与阴影已按 [素材修正报告](docs/素材修正报告.md) 更新。实施共4阶段，不打包构建；完成Creator预览即可。

运行 `python3 docs/工具/检查交付.py` 检查素材基线。需要比较时，在该命令之后添加另一工程的绝对路径。该检查不代表游戏可玩或已完成阶段验收。
