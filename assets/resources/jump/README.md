# 跳一跳资源基线

本目录保存250项已提取媒体和派生静态模型，两个对比工程保持相同内容与UUID。来源、用途和导入引用见项目docs；original为原包媒体，derived为派生学习素材。原版排行榜、消息、皮肤中心和多人素材仅归档。

数字裁片使用digit_1—7命名，unused_blank是空白区域；它们用于编号平台参考，HUD使用num.ttf。numbered_block_0—6.glb保留原源码h索引，实际显示1—7。43个平台阴影材质已修正为BLEND，编号文字MASK保持不变。源图、模型几何/UV/内嵌图片未改变；详细映射和验证见docs/素材修正报告.md。

修正版作为后续只读基线。新增场景、包装Prefab和材质放独立目录，UI精灵帧在阶段03按需通过Creator生成。
