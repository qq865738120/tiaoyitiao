- [素材使用清单 JSON](数据/素材使用清单.json)：250 条素材的用途、来源哈希、Creator UUID 和子资源。
- [素材使用清单 CSV](数据/素材使用清单.csv)：便于筛选、核对与表格阅读。
- [素材来源映射](数据/素材来源映射.json)：原提取文件到当前 `db://assets/...` 的映射。
- [共享基线](数据/共享基线.json)：冻结的资产内容及 Creator 生成元数据哈希。
- [命令清单](数据/命令清单.json)：命令 id、阶段文档及正文哈希。

## 原包与离线浏览

[完整提取包说明](参考资料/原始提取包/README.md)、[素材浏览器](参考资料/原始提取包/素材浏览.html)、[图片总览](参考资料/原始提取包/图片总览.jpg) 均保留在本工程。
若浏览器对 `file://` 加载脚本有限制，可在该目录运行本地静态文件服务后浏览。此浏览器用于核对原始素材，不是 Cocos 游戏实现。

本轮为4阶段方案，最终在Creator预览完成；不要求打包构建。

后续智能体先执行当前阶段，验收通过后更新该阶段交接记录。文档里的任务勾选均为计划，不能视为已实施。
