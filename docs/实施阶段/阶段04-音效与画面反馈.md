# 阶段 04：音效与画面反馈

版本1.1，当前待实施。目标：加入有限的核心声画反馈，校准原图风格及资源清理。

## 前置与材料

阶段01—03完成单人闭环，事件不会重复触发；读取前置交接。

必读根AGENTS.md、docs/README.md、游戏设计、素材清单与使用明细、素材修正报告、总实施文档，以及游戏设计第 6—7 节；素材音频/背景/静态GLB限制；前置事件契约。

本阶段素材：scale_intro/scale_loop、success、combo1—8、fall/fall_2、start；perfect/pop试听后可备用。gradient_0—6与现有阴影/角色纹理。禁止使用缺失store/water音频或联网补素材。

GLB引用Creator生成的子资源，3D纹理按Texture引用；UI需要的SpriteFrame在阶段03通过Creator生成。digit_1—7是编号台裁片，不是HUD完整数字字体。模型已修正阴影BLEND；角色动画仍需实现。只操作当前工程，遵守已修正共享素材的只读边界。

## 完成条件

蓄力音不会一直响；按combo阶梯播放音阶；失败只一次；角色动画不改变落点；30/60/120帧动画时间一致；静态GLB不假称有骨骼动画；视觉随机不改变R11平台序列。

执行本阶段相关规则用例、保存重开与Creator预览，记录通过/失败/未执行及原因。每阶段就地修复问题；不另设验收或交付阶段，不执行打包构建、包体优化、平台发布或真机验证。
