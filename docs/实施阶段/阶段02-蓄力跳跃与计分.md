# 阶段 02：蓄力跳跃与计分

版本1.1，本工程阶段02已完成（2026-10-02，Creator桌面核心玩法范围）。物理触摸设备与真实OS后台切换未实测，相关适配/规则测试不冒充设备验收；详细证据见 [阶段02交接](../交接记录/阶段02.md)。目标：一次完成输入、蓄力、弹道、平台生成、落点、计分和失败，形成可连续游玩的核心。

## 前置与材料

阶段01的配置、测试入口、3D场景、角色与平台包装已完成，读取阶段01交接记录。

必读根AGENTS.md、docs/README.md、游戏设计、素材清单与使用明细、素材修正报告、总实施文档，以及游戏设计第2—5节、跨阶段接口及验收R01—R12/R14/R15；阶段01的角色脚底和平台基准。

GLB引用Creator生成的子资源，3D纹理按Texture引用；UI需要的SpriteFrame在阶段03通过Creator生成。digit_1—7是编号台裁片，不是HUD完整数字字体。模型已修正阴影BLEND；角色动画仍需实现。只操作当前工程，遵守已修正共享素材的只读边界。

## 完成条件

中点最高3.6，终点回到相同topY，距离与holdSeconds一致；长按不自动起跳；同一次release不触发两跳；飞行按键不缓存；暂停恢复不补算后台时间。 seed相同平台参数相同；生成器全部可达；目标台只记分一次；落回当前台保持位置并可再跳；落空只触发一次终局；两个方向相机移动后仍能完整看到下一目标。

执行本阶段相关规则用例、保存重开与Creator预览，记录通过/失败/未执行及原因。每阶段就地修复问题；不另设验收或交付阶段，不执行打包构建、包体优化、平台发布或真机验证。
