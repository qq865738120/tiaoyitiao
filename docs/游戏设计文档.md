# 游戏设计文档：跳一跳核心玩法

版本1.1 / 2026-09-30。目标是用 Cocos Creator 3.8.8 学习并复刻单人核心体验，同时为两个独立 Game Agent 实施工程提供相同输入。素材来自本机已解析的电脑版小游戏缓存；这份设计采用明确、可测试的学习版规则，不宣称是原版全部机制的精确还原。

运行配置与回放中的共同 `configVersion` 为 `jump-learning-1.0`，对应本设计和验收基准；实施中若调整规则或数值，必须更新版本并记录对比条件变化。

## 1. 产品目标与范围

玩家观察目标平台距离，按住蓄力，松开跳跃，落在下一个平台得分；连续命中中心获得递增奖励，落空结束，查看本局及本地最高分并重开。不开网络也能完成全部闭环。

| 必须实现 | 明确不实施 |
| --- | --- |
| 默认角色、方形/圆形平台、随机方向及间距 | 排行榜、好友排行、消息、皮肤中心、换装、多人 |
| 触摸/鼠标/空格蓄力及跳跃 | 分享、邀请、广告、活动奖品、擂台、账号授权 |
| 落点判定、普通得分、中心连击、失败 | 原版特殊平台停留奖金、扫码、红包、支付、在线皮肤 |
| 开始页、游戏 HUD、暂停、结算、重开、返回 | 微信顶部窗口栏、菜单胶囊和宿主 WASD 圆盘 |
| 本地最高分、基础音效、阴影与背景变化 | 服务端、SDK、用户资料、微信运行环境依赖 |

保留全部素材是为了资料完整性；备用素材不扩大需求。优先真实 3D 正交画面，使用已有 GLB；不把截屏背景当作整张游戏画面。

## 2. 操作与状态

触摸按下、鼠标左键按下或空格按下开始蓄力，对应同一输入源松开时起跳。只允许一个输入拥有者；重复 keydown、多指、混合鼠标/键盘不能产生第二次跳跃。UI 按钮消费输入，不触发蓄力。

状态流：`menu → ready → charging → airborne → landing → recentering → ready`；落空进入 `falling → gameover`。暂停保存原状态并冻结模拟；恢复不追加后台时间。开始新局生成新 runId，清理所有输入、动画、音频和异步回调。

| 状态/事件 | 结果 |
| --- | --- |
| ready 按下有效输入 | charging，记录模拟 tick 与输入拥有者 |
| charging 有效松开，时长 ≥ 0.08 秒 | airborne，锁定起点、方向、距离和目标 id |
| 时长不足 0.08 秒或取消输入 | 返回 ready，不跳、不记分 |
| 飞行、落地、相机移动期间按下 | 忽略，不缓存一次未来起跳 |
| 飞行落到目标平台 | 只计分一次，更新平台后移动相机 |
| 落回当前平台 | 不计分、不中断已有中心连击，恢复 ready |
| 落到其他位置/旧平台 | falling，再显示 gameover；只结算一次 |
| 暂停、失焦、切后台发生于蓄力 | 取消蓄力并恢复外观；恢复后必须重新按下 |
| 失焦或切后台发生于飞行 | 暂停模拟，恢复后继续，不突然补算一大段时间 |

暂停界面提供继续、重开、回主页；回主页和重开都中止旧 runId，旧计时器不能修改新局。

## 3. 世界坐标、跳跃与数值契约

X/Z 为地面轴，Y 向上。角色逻辑位置为脚底接触点。平台逻辑根节点位于台面中心；Visual 子节点补偿模型的原始原点、阴影及高度。默认平台视觉宽深 10、高 5.5，水平缩放 0.8—1.0，高度保持一致。相邻目标始终沿 +X 或 +Z，不让玩家控制四方向。

下表是**学习版共同初始参数**，不能误称为从原包验证的物理参数。原包 `gravity=720`、`velocityY=135` 等记录在参考报告，但本实现不直接复制依赖旧帧循环的数值。

| 配置 | 初始值 | 含义 |
| --- | --- | --- |
| 固定模拟步长 | 1/60 秒 | 输入回放以整数 tick 表示，与渲染帧率分开 |
| 最小有效蓄力 | 0.08 秒 | 不足则取消 |
| 最大蓄力 | 1.20 秒 | 保持按住时封顶，不自动起跳 |
| 距离 | `4 + 18q` | `q=clamp((holdSeconds-0.08)/1.12,0,1)` |
| 竖直初速 | 24 单位/秒 | 固定 |
| 重力 | 80 单位/秒² | 同台面高度时飞行 0.60 秒，最高 3.60 单位 |
| 平台水平 scale | [0.8,1.0] | X/Z 同比，Y 不缩放 |
| 相邻边缘间隙 | [2,8] 单位 | 根据当前/目标半宽计算中心距离 |
| 角色落点安全半径 | 0.30 单位 | 从有效台面边界向内收缩 |
| 中心判定半径 | 0.50 单位 | 台面中心平面距离 |
| 相机平移 | 0.25 秒 | 可调视觉参数，不改变模拟结果 |
| 测试种子 | 20260930 | 固定测试入口；正式新局可随机但记录种子 |

目标平台生成沿 +X 或 +Z；起跳方向则从当前实际脚底指向目标中心，`direction=normalize(targetCenterXZ-startFootXZ)`，在释放时锁定。这样即使上次落在台面侧边，也不会因沿平台中心轴平移而对不齐下一圆台。方向由游戏决定，玩家只控制蓄力距离。

同高度跳跃：`T=2*24/80=0.6`，`xz(t)=startXZ+direction*distance*t/T`，`y(t)=startY+24t-40t²`。角色旋转、压缩和拉伸仅作用于 Visual，不修改逻辑位置、判定半径或跳跃距离。落地使用下降阶段跨越台面高度的解析时刻，禁止靠某渲染帧的位置恰好接近地面来决定成败。

模拟按固定 tick 前进，渲染插值只影响显示。每渲染帧最多补 5 个 tick，积压过多时冻结并提示暂停，不静默丢 tick 或继续加长蓄力。测试回放直接按 tick 驱动，不依赖手动按键的真实时钟误差。

## 4. 平台生成和落点

使用确定性 xorshift32（非零初始 seed）：每次依次执行 `s ^= s<<13; s ^= s>>>17; s ^= s<<5; s >>>= 0`，随机浮点为 `s/4294967296`。零seed固定改为1。每个平台消费4次随机值，顺序为方向、scale、间隙、模型：方向值<0.5为+X，否则+Z；scale=0.8+0.2u；gap=2+6u；模型按下方白名单顺序取floor(10u)。前两个固定平台不消费随机值；装饰和背景使用独立视觉随机流，不改变平台序列。

相邻中心距 = 当前沿跳跃轴半宽 + 目标半宽 + gap；圆形按半径计算。按上述范围中心距为 10—18，最大跳距 22。从实际脚底沿锁定方向射线计算目标安全台面的距离区间，并检查与[4,22]的交集，不仅检查两个平台中心距；失败应报配置问题，不无声地产生不可能平台。共同随机与平台数值样本见 `docs/数据/验收基准.json`。

核心模型白名单为 `block_00/01/03/04/08/11/12/33/34/35`；其中 03 使用圆形台面，其余矩形。模型只决定外观与台面形状，不附带商店、红包、音乐停留奖励。前两块使用 00、01，scale=1，第一目标中心距 14，便于学习和回归；之后按 seed 生成。

方形安全落点：`abs(dx) <= halfX-0.30` 且 `abs(dz) <= halfZ-0.30`。圆形：`dx²+dz² <= (radius-0.30)²`。边界相等算成功，浮点容差统一为 1e-6。只对锁定目标及当前平台判定；不能把平台阴影、圆环、侧面或已回收的平台当作台面。模型的包围盒包含阴影，不能直接拿整体包围盒作为可站立范围。

维持当前平台、下一目标、少量历史平台与一个预告平台；平台池有明确上限（建议 8），回收时重置所有状态和材质实例。生成失败不改变当前分数。相机只在成功落地后跟随，蓄力与飞行期间不转向或改变缩放。

## 5. 计分与存储

普通命中目标加 1，中心连击重置为 0。中心命中使 streak+1，奖励 `2*min(streak,8)`：2、4、6、…、16；超过 8 次继续 +16。落回当前台不加分，连击保留；落空直接结算。每次 jumpId 最多产生一次得分事件和一次终局事件。仅展示“本次得分”和“历史最高分”，没有排名、昵称或头像。

最高分在本机按项目命名空间保存整数；可使用项目 package UUID 作为 namespace，不复制另一个工程的运行存档。读到缺失、负数、非有限数或损坏内容时回退 0。存储写入失败不阻塞重开。对比测试先重置存档，再注入相同本地最高分作为前置条件。调试入口与存档重置只在开发模式出现。

## 6. 画面与界面

独立 3D World + 正交 WorldCamera + 2D Canvas/UI 相机。镜头初始为对角俯视（俯角约 35°、地面方位角约 45°），用实际预览校准；左右两个跳跃方向都投影到上方。角色偏下，当前与目标平台完整可见，分数固定左上角安全区。

内容设计分辨率 414 × 736，宽度适配，高度留弹性；窄屏确保按钮可点、分数不遮挡目标，宽屏保留竖屏内容区并扩展背景。参考图不含顶部微信宿主栏。UI 操作区域不传递到世界输入。

| 页面 | 元素和行为 |
| --- | --- |
| 开始 | title.png、默认角色、平台、play.png 按钮；无底部三入口或多人文字 |
| 游戏 | 左上数字、角落暂停按钮、初局“按住蓄力，松开跳跃”短提示；首个有效跳跃后隐藏 |
| 暂停 | 暗色遮罩、继续、重开、回主页；无分享 |
| 结算 | 本次分数大字、replay.png、2d/new_home.png、本地最高分；不留空的排行榜占位框 |

num.ttf 用于数字；中文使用系统字体/Creator 支持的默认字体，不把只有少量字形的 typeface JSON 当作中文字体。开始/重开图片已含图标和文字，不额外叠一份相同 Label。按钮保留图像比例，点击区域至少 44 × 44 设计像素；暂停按钮用新建简单图形和文字即可。

平台 GLB 已包含贴图阴影，优先保留并在材质透明度/深度设置上校正；避免同时再叠一份相同阴影。角色使用独立脚下接触阴影，并随跳高改变大小/透明度。背景首局使用 gradient_5.png 的浅黄系，可按固定视觉序列换色，不在每帧随机变化。环境光与平行光控制为低饱和明快效果，不使用过度金属反射。

## 7. 声音与反馈

首次玩家手势后启用音频。蓄力播放 scale_intro，再进入 scale_loop 循环；松开、取消、暂停、结束必须停止。普通落地 success，中心落地 combo1—8（按封顶 streak 选择），失败 fall 或 fall_2；事件去重，不重叠播放一堆成功音。start 可作进入新局反馈，perfect 为中心命中备用，pop 为轻 UI 反馈备用，实际试听后定音量并写入素材使用记录。

蓄力压缩、起跳舒展、空中翻转、落地缓冲和中心短闪光均通过 Cocos 时间动画实现，GLB 没有可直接播放的动画剪辑。无必要持续背景音乐，不要求缺失的 store.mp3、water.mp3。所有循环音、特效、Tween 与事件监听在新局/销毁时清理。

## 8. 成功标准与证据边界

按 [验收与对比测试](验收与对比测试.md) 验证规则、预览、存档、适配、30/60/120 FPS 回放。相同 seed+输入 ticks 应得到相同平台参数、落点分类和分数，视觉可存在渲染帧差异。文件导入成功不等于模型颜色已校准；截图正确不等于碰撞正确；本任务以Creator预览为最终运行入口，不执行Web/微信打包构建或发布，也不要求真机验收。本阶段交付不发布线上产品，素材使用授权未在本次确认。
