## 接口与取消/暂停策略

- `JumpGameplay`：`start(seed?) / home / press(source) / release(source) / cancel(source?,reason?) / pause(reason?) / resume / step`返回是否接受；只读`state/foot/platforms/current/target/holdSeconds/results`，`drainEvents()`一次取出队列。score作为机器原子命令，表现不能设置分数/坐标驱动规则。
- `FixedTickClock.advanceFrame(delta,onTick)`：每帧最多5tick；积压冻结不丢tick；resume跳过首帧墙钟，分帧恢复已积压模拟，暂停期间墙钟不补算蓄力/飞行。
- `JumpPlan`：runId/jumpId/startTick/startFoot/directionXZ/distance/flightTime/targetId；下降解析时刻唯一落点，不依赖Collider、阴影或视觉大小。
- `PlatformGenerator`：初始两台不耗随机；后续消费顺序固定，实际偏脚底下一目标安全可达在计分前验证。普通历史只用于表现，规则只查当前/目标。
- `InputAdapter`：物理down集合与规则owner分离；竞争输入release/cancel不影响owner；忙态拒绝不缓存；reset清owner但仍按下的键/触点需释放再按。unbind清down与所有监听。全局input显式hitTest活跃Button/EditBox/BlockInputEvents和HTMLform焦点。
- `PlatformPool.sync/clear/destroy`：最多8包装，按白名单顺序Inspector绑定10Prefab，实例材质还原共享引用，原资产不改；回收清view metadata/回调/局部变换并递归停Tween。当前包装没有其他自定义定时组件；未来添加时须扩展生命周期契约。
- `AvatarView.render`：根由规则脚底/渲染插值驱动；rawFootY=.0837，压缩Y与原点补偿只在Visual；阴影不参与碰撞。`CameraFollow`相对当前/目标中点保留阶段01offset，成功后模拟15tick移动，pause-safe。
- 新局清输入owner、旧计划/计数/回放/元数据，重建seed序列；已分配池壳可保留8个而不是销毁重建。DomainEvent只消费一次，旧run/jump被机器拒绝。
- P暂停/继续、R重开，场景右上开发控件可点击；DEBUG F9使用普通press/release完成24跳并暂停，没有测试接口设置位置或分数。
- 可选Bridge只发布真实状态副本：jump、jumpPlatforms、jumpResults、jumpInputs、jumpView；缺失Bridge不影响玩法。销毁clearState，数组最多最近32项但工具单数组可能裁剪到20项，不能把省略结果当作完整验收。
