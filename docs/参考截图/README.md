| 文件 | 可参考内容 | 本工程删除的内容 |

三图顶部约 88 像素为微信桌面宿主窗口栏，包括标题、菜单和窗口控制；不属于游戏 Canvas。中央半透明 WASD 圆盘按电脑版宿主辅助覆盖层处理，本工程不复制该圆盘。暂停功能使用本游戏自己的小按钮。桌面输入仅鼠标按住/松开与空格键，不做角色四方向移动。

设计分辨率为 414 × 736 的游戏内容区。比较布局时去除宿主栏，以归一化位置而非原图绝对像素对齐。首页标题约内容高度 23%，开始按钮约 69%；游戏角色落点偏下，目标偏上；结算页大数字约 18%，重开按钮约 82%。这些是从截图估算的布局起点，需要实际预览校正。

静态截图不能证明蓄力曲线、精确碰撞范围、原版计分、动画时长和音量。本项目的实现契约由游戏设计文档明确制定，不宣称这些参数逐项与原版相同。
