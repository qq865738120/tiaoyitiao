## 2. Creator导入和资源引用

路径前缀为 `db://assets/resources/jump/`。Creator 3.8支持glTF/GLB导入，导入后生成Prefab、Mesh、Material、Texture等子资源；不能把GLB文件名直接交给运行时加载器当Prefab。[官方模型说明](https://docs.cocos.com/creator/3.8/manual/zh/asset/model/mesh.html)、[官方glTF映射](https://docs.cocos.com/creator/3.8/manual/zh/asset/model/glTF.html)。

本次Creator生成了图片的Texture子资源，图片默认导入类型为texture，当前**没有SpriteFrame子资源**。3D贴图按Texture引用；阶段03通过Creator导入设置为title/play/replay/new_home等UI用图生成SpriteFrame，再绑定Sprite/Button并记录实际UUID。禁止凭图片根UUID猜一个SpriteFrame。

GLB模型根UUID及子资源UUID都已写入JSON。优先在Creator中引用生成的模型Prefab子资源，再制作本工程自己的包装Prefab。不要自行拼 `model/scene` 一类运行时路径；若要动态加载，先用资产工具查询实际子资源并在AssetCatalog中保存明确引用。

图片wrap默认repeat，UI/渐变背景使用时需要按用途设置clamp并正确选取透明混合；阶段02/05再用编辑器调整并记录设置变化。两工程初始metadata一致，未来阶段的设置/新Prefab各自独立，不能为了保持对比而自动覆盖另一工程。

GLB含嵌入纹理，原PNG同时保留供校对，避免重复预加载。GLB无动画剪辑/骨骼，角色蓄力/跳跃/翻转要在Cocos制作；模型内未导出原动态粒子和Three文字。平台阴影已含在模型层级中，整体包围盒不能当有效台面。
