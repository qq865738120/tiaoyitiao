# Game Agent 演示插件与四阶段会话

本工程已包含 Game Agent **0.4.0** 只读演示插件。使用 Cocos Dashboard 打开工程（Creator 3.8.8），从扩展菜单打开 **Game Agent 演示版**，点击历史会话入口切换阶段。无需模型配置或登录；不能发送消息、审批、运行工具或继续开发。

## 插件文件

- [独立安装 ZIP](game-agent-demo-0.4.0.zip)：ZIP 内只有 `game-agent-demo/` 一个根目录，可解压到其它演示工程的 `extensions/`。
- [已安装插件](../../extensions/game-agent-demo/README.md)：当前工程已解压，可以直接加载。若 Creator 已打开，退出后通过 Dashboard 重开。
- [第三方声明](../../extensions/game-agent-demo/THIRD_PARTY_NOTICES.md)：构建实际使用的第三方库许可证。

ZIP 是通用查看器空壳，历史单独存放在当前工程 `.gameagent/.data/session`，不在插件内。移动到其它工程时，应同时复制归档清单内的 `.gameagent/.data/layout.json` 和 `session` 历史文件。

消息数是持久化消息条数，一条助手消息含多个推理、工具和步骤 part，不代表只执行了一次工具。归档保持原始会话 ID、时间戳、正文和结果；各阶段验收以 [交接记录](../交接记录/README.md) 为准，运行状态 `completed` 仅表示该轮会话结束。

[演示会话清单](../数据/演示会话清单.json) 固定287个历史文件的SHA-256：布局标记、索引、4个完整Session v3、4个主日志、9个子任务日志、4份任务日记及66组原图/显示图/缩略图/元数据。保留了失败、撤销的验收要求和未完成项。

历史工具结果可能包含原开发机的绝对路径，这些是历史文本，不是当前工程路径。演示版不会访问原机文件或加载网络媒体；图片在会话中显示为占位，实际图片保留在 `session/images/<会话ID>/<预览ID>/`，最终阶段截图也可在 [阶段04截图](../验收证据/阶段04截图) 查看。

恢复快照、工作区标签状态、临时命令输出、工具事务、记忆、缓存和模型设置继续由Git忽略。`.gitignore` 只对本次四阶段历史做精确文件放行，不共享其它会话。

## 本地核验

在工程根目录运行：

```sh
python3 docs/工具/检查演示交付.py
```

该命令检查文件哈希、四阶段索引、图片内容摘要、插件ZIP与已安装文件一致性，以及Git历史放行与私有运行数据忽略边界。它不会修改历史，也不需要原插件源码。
